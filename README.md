# Wildlife Monitoring and Conservation using KNN

This project is an AIML mini-project that classifies wildlife animal images using the K-Nearest Neighbors (KNN) algorithm.

## Features
- Animal image classification
- Uses Kaggle Animals-10 dataset
- Image preprocessing using OpenCV
- KNN Machine Learning algorithm
- Confusion Matrix and Accuracy Evaluation
- Google Colab implementation

## Technologies Used
- Python
- OpenCV
- NumPy
- Scikit-learn
- Matplotlib

## Dataset
Animals-10 Dataset from Kaggle

## Animal Classes Used
- Dog
- Cat
- Elephant
- Butterfly
- Horse
- Sheep

## Model
K-Nearest Neighbors (KNN)

## Platform
Google Colab
